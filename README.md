### How to use

1. Open Parabolic  
2. Click **Download**  
3. Click the **Add Batch** button  
4. Select the corresponding show’s text file  
5. Let Parabolic discover the media  
6. After discovery, download the complete show in bulk

> **Note:** Networks listed have free tiers and shows listed contain no DRM or copy protection. YT-DLP is free and open source software, and Parabolic is a frontend UI for it.  
> You can use the batch file in Parabolic for quickly downloading the franchise for offline viewing.
